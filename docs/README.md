# Documentacion activa del proyecto

Este directorio conserva solo la documentacion operativa actual del sistema.

## Indice minimo

- `ARQUITECTURA.md`: mapa de modulos, rutas y ubicacion de funcionalidades.
- `COMANDOS_SERVIDOR.md`: comandos de despliegue, reinicio y diagnostico en servidor.
- `PASOS_ACTIVAR_AFIP.md`: activacion de certificados y relacion en AFIP.
- `INTEGRACION_CLOVER.md`: guia de integracion Clover (estado actual y flujo).

## Referencias en raiz

- `../README.md`: estado general del proyecto.
- `../INSTALL.md`: instalacion base del sistema.

## Criterio de esta carpeta

- Solo se mantienen archivos vigentes para operacion diaria.
- Documentacion historica y notas de iteraciones fueron eliminadas para reducir ruido.
- Si se crea documentacion nueva, debe ser util para operacion o soporte tecnico.
